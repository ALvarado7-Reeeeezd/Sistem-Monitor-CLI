# 📊 Sistem Monitor CLI

A lightweight real-time system monitoring CLI application built with Python.

## 🚀 Features
- **Real-Time Monitoring**: CPU & RAM metrics updated dynamically.
- **Clean CLI UI**: Styled with `rich` library for an aesthetic terminal experience.
- **System Metrics**: Low-level metrics fetched using `psutil`.
